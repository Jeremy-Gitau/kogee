# Kogee

**Kotlin Multiplatform knowledge graph and AI context engine**

Kogee gives AI agents the context they need from your Kotlin Multiplatform app — without sending them the entire database, conversation history, or application state. Instead of dumping everything into a prompt, it represents your app's entities and relationships as a graph, then retrieves only the small, relevant subgraph an agent actually needs to answer a question.

## Status

Early development — building in public, from scratch. Not yet functional, not yet published. Follow progress on the [project board](https://github.com/users/Jeremy-Gitau/projects/2).
